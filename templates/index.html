System Workflow

How SkinNova Works

SkinNova follows a complete AI diagnosis pipeline from image upload to explainable prediction, confidence scoring, and clinical recommendation generation.

01

Input Dermoscopic Image

User uploads a dermoscopic skin lesion image through the web dashboard.

02

Image Quality Assessment

The system checks blur, resolution, noise, and poor-quality image conditions.

03

Preprocessing & Enhancement

Hair removal, CLAHE, and bilateral filtering improve lesion visibility.

04

Lesion Segmentation

U-Net or DeepLabV3+ isolates the lesion region from the background.

05

Hybrid Deep Learning

EfficientNetV2 extracts local features while Vision Transformer captures global context.

06

Explainable AI

Grad-CAM and LIME generate visual explanations for model predictions.

07

Clinical Report

The system produces prediction, confidence score, risk level, and recommendation.

Dataset & Validation

Research Dataset & Cross-Dataset Validation

SkinNova uses benchmark dermoscopic datasets for training, testing, and external validation to improve robustness, reduce dataset bias, and support real-world clinical reliability.

HAM10000

Primary Training Dataset

Used as the main dataset for training and internal validation of the seven-class skin lesion classification model.

  • 10,000+ dermoscopic images
  • Seven lesion categories
  • Metadata-based class labels
  • Suitable for multi-class classification

ISIC Archive

External Validation

Used to evaluate cross-dataset generalization and test whether the trained model performs reliably on unseen data.

  • Independent dermoscopic images
  • Challenge-based benchmark data
  • External model evaluation
  • Generalization analysis

PH2 / PAD-UFES-20

Additional Research Testing

Additional datasets can be used for robustness testing, real-world variation analysis, and clinical-style evaluation.

  • Dataset diversity testing
  • Clinical image variation
  • Model robustness study
  • Bias reduction support

Cross-Dataset Validation Strategy

The proposed SkinNova framework follows a research-oriented evaluation strategy where the model is trained on HAM10000 and externally tested on ISIC, PH2, or PAD-UFES-20 datasets. This helps verify whether the model is learning meaningful lesion features instead of memorizing dataset-specific patterns.

Reduces dataset-specific bias
Measures real-world generalization
Supports research-level evaluation
Improves clinical trustworthiness
